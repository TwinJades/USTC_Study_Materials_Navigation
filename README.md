# 也西书架 · 中科大本科课程资料导航

中国科学技术大学本科课程资料导航站，索引各课程的往年试题与解析、作业小测、学习资料、教材与参考书及大作业，只登记可核实的原站入口，不托管第三方文件。

## 在线使用

- **[打开也西书架](https://twinjades.github.io/USTC_Study_Materials_Navigation/)**
- 点击站点右上角公告栏可查看阶段性大更新与社区衍生项目；完整历史变更见 [更新日志](CHANGELOG.md)。

> **本校同学交流群**：QQ 群 `1135099242`（仅面向中科大在校同学）。找资料、反馈问题或提供来源线索可直接进群；有意参与维护的同学欢迎进群私聊群主（见文末 [招募共同维护者](#招募共同维护者)）。

## 怎么找资料

1. **找课程**：输入课名或官方课号，或按课程类别、学科标签、资料类型与收录状态筛选；同名及相近课程可通过课号区分。
2. **找试题**：筛选「试题与解析」后可继续按年份筛选；进入课程页可查看已知年份或学年、卷别、形式及解答情况。
3. **查出处与核验信息**：简洁模式保留原始出处与最直接的可用入口；需要查看作者、全部入口、核验依据或直链文件取样（SHA-256、字节数与取样日期）时，可切换到详细模式。

- **访问限制**：标记「需登录」的评课社区条目仅链接至匿名可定位的原帖，请登录后在原帖下载附件；本站不保存登录凭据或临时签名地址。
- **收录范围**：目录覆盖 **2025 秋—2026 秋** 官方本科开课，实时课程与资料统计见网站首页及 [来源、检索记录与致谢](docs/sources-and-search.md)。「暂未收录」表示当前索引尚未记录可核验资料，不代表课程没有资料。

# 也西书架 · 中科大本科课程资料导航

整理中国科学技术大学本科各门课程的公开学习资料——涵盖往年试题与解析、作业小测、讲义笔记、公开教材与大作业，按官方课号索引，直接指向原站入口。

## 在线使用

- **[打开也西书架](https://twinjades.github.io/USTC_Study_Materials_Navigation/)**：覆盖 **2025 秋—2026 秋** 本科开课，当前收录统计见站点首页与 [来源、检索记录与致谢](docs/sources-and-search.md)。
- **站内公告与更新**：点击右上角公告栏可查看近期更新与衍生项目，完整记录见 [更新日志](CHANGELOG.md)。

> **中科大在校同学交流群**：QQ 群 `1135099242`。找资料、反馈问题或提供线索都可以直接进群；想一起参与维护的同学欢迎直接私聊群主（见文末 [招募共同维护者](#招募共同维护者)）。

## 怎么找资料

1. **找课程**：直接输入课名或官方课号搜索，同名课可通过课号区分；右上角切到详细模式可展开筛选区，按类别、学科、资料类型与资料情况组合筛选。
2. **找试题**：在筛选区选择「试题与解析」后可继续按年份筛选；进入课程页可查看具体年份或学年、期中期末、原卷或回忆版以及是否附解答。
3. **查详细出处**：课程页默认简洁模式，保留出处与最直接的可用入口；切到详细模式可查看作者、全部入口、来源说明及已校验文件的 SHA-256 与大小。
4. **访问原站与补充线索**：标有「需登录」的评课社区条目直接跳转到原帖，登录评课社区后即可下载附件；遇到「暂未收录」的课程，表示本站暂未收录这门课的资料，欢迎随时补充。
